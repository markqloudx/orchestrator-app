Governance Principle

Cost Center is the parent. Every project must belong to a registered Cost Center. Every project must have a registered source repository. Every production change must have an approval. Every deployment must carry project, repository, commit, release and metadata information.

databricks.yml

bundle:
  name: customer-analytics

include:
  - resources/*.yml

variables:
  cost_center: "CC-4100"
  project_id: "PRJ-001"
  change_id: "CHG-2026-0042"
  release_version: "v1.0.184"

targets:
  dev:
    mode: development
  prod:
    mode: production

resources:
  jobs:
    customer_analytics_job:
      name: customer-analytics-${var.project_id}
      tasks:
        - task_key: customer_processing
          notebook_task:
            notebook_path: /Workspace/customer-analytics
