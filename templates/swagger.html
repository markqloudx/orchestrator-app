Dashboard API Docs

📚 Databricks Orchestrator API

Version 1.0.0

Base URL: /api/

🔗 Endpoints

Cost Centers

GET /cost-centers
Get all cost centers
POST /cost-centers
Create cost center

Projects

GET /projects
Get all projects
POST /projects
Create project
GET /projects/{id}
Get project with repo status
GET /projects/{id}/branches
Get project branches
GET /projects/{id}/commits
Get project commits

Changes

GET /changes
Get all changes
POST /changes
Create change request
POST /detect-changes
Detect changes between repos

Approval & Deployment

POST /approve/{id}
Approve a change
POST /reject/{id}
Reject a change
POST /deploy/{id}
Deploy to PROD

📊 GitHub APIs

GET /github/verify/{repo}
Verify GitHub repository
GET /github/branches/{repo}
Get repository branches
GET /github/commits/{repo}/{branch}
Get commits from branch

📦 Databricks APIs

GET /databricks/jobs/list
List Databricks jobs
POST /databricks/jobs/run
Run a Databricks job

📋 Logs & Audit

GET /deployment-logs
Get deployment logs
GET /audit
Get audit trail
GET /health
Health check
