📚 API Documentation

REST API endpoints for the Databricks Orchestrator.

Base URL

/api/

Endpoints

MethodEndpointDescription
GET/api/cost-centersGet all cost centers
POST/api/cost-centersCreate cost center
GET/api/projectsGet all projects
POST/api/projectsCreate project
DELETE/api/projects/{id}Delete project
GET/api/projects/{id}/verifyVerify GitHub repo
GET/api/changesGet all changes
POST/api/changesCreate change request
POST/api/detect-changesDetect changes
POST/api/changes/{id}/approveApprove change
POST/api/changes/{id}/rejectReject change
POST/api/changes/{id}/deployDeploy to PROD
GET/api/deployment-logsGet logs
GET/api/auditGet audit trail
GET/healthHealth check

Example: Detect Changes

curl -X POST /api/detect-changes \
  -H "Content-Type: application/json" \
  -d '{"project_id": "PRJ-001", "branch": "main"}'

Response:
{
  "success": true,
  "changes": [
    {"file": "notebook.py", "type": "new"}
  ],
  "count": 1
}
