📚 API Documentation

REST API endpoints for the Databricks Orchestrator.

Base URL

/api/

Authentication

All API endpoints use the Databricks App's environment variables for authentication.

Endpoints

MethodEndpointDescription
GET /api/cost-centers Get all cost centers
POST /api/cost-centers Create a new cost center
GET /api/projects Get all projects
POST /api/projects Create a new project
GET /api/projects/{id}/verify Verify GitHub repository
GET /api/projects/{id}/branches Get repository branches
GET /api/projects/{id}/commits Get commits from branch
GET /api/changes Get all changes
POST /api/changes Create a change request
POST /api/detect-changes Detect changes between repos
POST /api/changes/{id}/approve Approve a change
POST /api/changes/{id}/reject Reject a change
POST /api/changes/{id}/deploy Deploy a change to PROD
GET /api/deployment-logs Get deployment logs
GET /api/audit Get audit trail
GET /health Health check
GET /swagger API documentation

Example: Detect Changes

curl -X POST /api/detect-changes \
  -H "Content-Type: application/json" \
  -d '{"project_id": "PRJ-001", "branch": "main"}'

Response:
{
  "success": true,
  "changes": [
    {"file": "notebook.py", "type": "new"},
    {"file": "databricks.yml", "type": "modified"}
  ],
  "count": 2
}

Example: Create Change Request

curl -X POST /api/changes \
  -H "Content-Type: application/json" \
  -d '{
    "project_id": "PRJ-001",
    "commit_sha": "8f3a91c2d7",
    "release_version": "v1.0.184",
    "description": "Analytics pipeline update"
  }'

Response:
{
  "success": true,
  "data": {
    "change_id": "CHG-2026-0042",
    "approval_status": "Pending",
    "deployment_status": "Blocked"
  }
}

Example: Approve and Deploy

# Approve
curl -X POST /api/changes/CHG-2026-0042/approve \
  -H "Content-Type: application/json" \
  -d '{"approver": "admin"}'

# Deploy
curl -X POST /api/changes/CHG-2026-0042/deploy \
  -H "Content-Type: application/json" \
  -d '{"deployer": "admin"}'
